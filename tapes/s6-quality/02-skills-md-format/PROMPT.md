## What this video shows

The complete anatomy of a `SKILLS.md` file, using the button component as the example. Covers every frontmatter field, all ten content sections in order, the code example conventions, and the `CLAUDE.md` writing style guide that keeps the library consistent.

## What you will see

1. YAML frontmatter — the six required fields.
2. Overview, when to use, when not to use — setting the context.
3. How it works — variants, states, and behaviour.
4. Code examples — HTML and Nunjucks for every variant.
5. Macro options, error messages, accessibility, do/don't, related.
6. The `CLAUDE.md` style guide — words to avoid and replacement patterns.

## What you will need

- Copy `workspace.example.yaml` to `workspace.yaml`: `cp workspace.example.yaml workspace.yaml`
- Clone `govuk-design-system-skills` into `workspace/`: `npx -y degit philsherry/govuk-design-system-skills workspace/govuk-design-system-skills`

## Series wrap-up

This is the final episode in the quality series and the final video in the collection. After watching this, a contributor has everything they need to write a new `SKILLS.md` file — the format, the style rules, and the linter to check their work.
