## What this video shows

Inside the accessibility auditor agent — what it knows, what it checks, and what its feedback looks like. Covers the WCAG 2.2 review criteria, the distinction between "must fix" and "should fix" severity levels, and a worked example showing how the agent cites specific success criteria and references skills files for the fix.

## What you will see

1. The agent's role and WCAG 2.2 Level AA baseline
2. Core knowledge — focus states, contrast ratios, assistive technology
3. The fourteen-item review criteria checklist
4. A worked example: spotting unlabeled inputs, citing WCAG 1.3.1
5. The eleven skills files the agent references

## What you will need

- Copy `workspace.example.yaml` to `workspace.yaml`: `cp workspace.example.yaml workspace.yaml`
- Clone `govuk-design-system-skills` into `workspace/`: `npx -y degit philsherry/govuk-design-system-skills workspace/govuk-design-system-skills`
- Familiarity with loading agents in Claude Code (see series 1, episode 3)
