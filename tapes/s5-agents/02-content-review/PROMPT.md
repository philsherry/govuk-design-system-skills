## What this video shows

Inside the content designer agent — reading level targets, sentence length rules, error message format, prescribed button labels, and worked examples showing the agent rewriting content to GOV.UK standards.

## What you will see

1. The agent's role — plain English, GOV.UK standards, accessibility
2. Reading level (age 9), sentence rules (15-20 words, never over 25)
3. Error message format, page titles, service naming, microcopy rules
4. The review criteria checklist
5. A worked example: rewriting a clunky error message to GOV.UK standard

## What you will need

- Copy `workspace.example.yaml` to `workspace.yaml`: `cp workspace.example.yaml workspace.yaml`
- Clone `govuk-design-system-skills` into `workspace/`: `npx -y degit philsherry/govuk-design-system-skills workspace/govuk-design-system-skills`
- Familiarity with loading agents in Claude Code (see series 1, episode 3)
