## What this video shows

What a multidisciplinary review looks like using agents in sequence. Eight agents review the same work, each catching things the previous ones were not looking for — from journey structure through to user research readiness.

## What you will see

1. The agents README describing the recommended review order
2. The interaction designer — journey structure and pattern choices
3. The content designer — plain English, error messages, reading level
4. The front-end developer — GOV.UK markup, `Nunjucks` macros, form structure
5. The accessibility auditor — WCAG 2.2, keyboard, screen readers
6. The performance analyst — Core Web Vitals, page weight, render-blocking resources
7. The QA tester — edge cases, cross-browser, assistive technology
8. The service designer — end-to-end service thinking, policy constraints
9. The user researcher — assumptions, test planning, research readiness

## What you will need

- Copy `workspace.example.yaml` to `workspace.yaml`: `cp workspace.example.yaml workspace.yaml`
- Clone `govuk-design-system-skills` into `workspace/`: `npx -y degit philsherry/govuk-design-system-skills workspace/govuk-design-system-skills`
- Familiarity with loading agents in Claude Code (see series 1, episode 3)

## Series wrap-up

This is the final episode in the agents series. Each video showed a different depth — the accessibility auditor in detail, the content designer in detail, then all eight in sequence to show how the disciplines complement each other.
