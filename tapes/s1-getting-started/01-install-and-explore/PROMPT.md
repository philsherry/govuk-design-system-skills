## What this video shows

How to install `govuk-design-system-skills`. This repository has no build step and no configuration required — installation is just cloning the repository.

## What you will see

1. Cloning the repository from GitHub
2. The top-level directory structure (four department directories)
3. The eight agent files listed by name

## What you will need

- Git installed on your machine
- A terminal

## What comes next

Once you clone the repository, you can load any of the skills files or agents directly into your AI tool of choice. The next video shows how to load a skills file into Claude Code.
