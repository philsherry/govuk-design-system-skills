## What this video shows

How to setup `govuk-design-system-skills` with Claude.ai on the web.
The setup is different from Cursor and GitHub Copilot — you attach SKILLS.md
files to a Claude.ai Project rather than copying them into a repository.

## What you will see

1. Browsing the available component and pattern `SKILLS.md` files in the terminal
2. Guidance on choosing which files to upload for a given prototype
3. An explanation of how to attach files to a Claude.ai Project

## What you will need

- Copy `workspace.example.yaml` to `workspace.yaml`: `cp workspace.example.yaml workspace.yaml`
- Clone `govuk-design-system-skills` into `workspace/`: `npx -y degit philsherry/govuk-design-system-skills workspace/govuk-design-system-skills`
- A Claude.ai account with Projects access

## Series wrap-up

This is the final episode in the setup series. All three videos cover the same goal — giving your AI tool accurate GOV.UK Design System context — but each tool has its own mechanism. Use whichever matches where you work.
