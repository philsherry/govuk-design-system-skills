# HMRC Design Patterns — Setup details

For the full installation guide (cloning the repo, setting up your AI tool), see the [root INSTALL.md](../../INSTALL.md).

This page covers HMRC-specific paths, class prefixes, and configuration snippets you will need when following the root guide.

## Paths

| Item | Path |
|------|------|
| Skills files | `hmrc-design-patterns/identifiers/`, `hmrc-design-patterns/service/`, `hmrc-design-patterns/identity/`, `hmrc-design-patterns/headers/`, `hmrc-design-patterns/pages/` |
| Agent files | `hmrc-design-patterns/agents/` |
| Foundations | `hmrc-design-patterns/foundations/` |
| GOV.UK core | `govuk-design-system/components/`, `govuk-design-system/styles/`, `govuk-design-system/patterns/` |

## Key details

| Detail | Value |
|--------|-------|
| CSS class prefix (core) | `govuk-` |
| CSS class prefix (HMRC) | `hmrc-` |
| Frontend packages | `govuk-frontend` (v5.x) + `hmrc-frontend` (v7.x) |
| Prototype Kit | GOV.UK Prototype Kit |
| Service standard | [GOV.UK Service Standard](https://www.gov.uk/service-manual/service-standard) (14 points) |
| Content style guide | [GOV.UK content style guide](https://www.gov.uk/guidance/style-guide) + [HMRC style guide](https://design.tax.service.gov.uk/hmrc-style-guide/) |
| Design patterns | [design.tax.service.gov.uk](https://design.tax.service.gov.uk/) |
